# NEXIS — Information Architecture & Navigation Hierarchy

## 1. Architectural Philosophy: The Career Intelligence Loop

Career management is not a linear form submission; it is a continuous feedback loop:
1. **Discover** gaps and market demands.
2. **Build** targeted artifacts (STAR resumes, code proof, interview readiness).
3. **Apply & Track** through transparent ATS workflows with warm referrals.
4. **Verify** credentials and progress.
5. **Command & Direct** autonomous AI agents to continuously scan and refine opportunities.

To deliver this experience without cluttering the screen, NEXIS groups its capabilities into **6 distinct clusters** accessible via a dual-navigation system:
- **Horizontal Pill Topbar**: Quick switching between primary high-frequency views (`Overview`, `Jobs`, `Resume`, `Skills`, `Analytics`, `Agents`).
- **Collapsible Warm Left Sidebar**: Exhaustive structured access to all 6 clusters with badges and agent activity status.

## 2. The 6-Cluster Navigation Architecture

```
                                  NEXIS COMMAND OS
                                          │
    ┌──────────┬──────────┬───────────────┴───────────────┬──────────┬──────────┐
    ▼          ▼          ▼                               ▼          ▼          ▼
[ COMMAND ] [DISCOVER] [ BUILD ]                       [ TRACK ]  [VERIFY]   [ SYSTEM ]
    │          │          │                               │          │          │
    ├─Overview ├─Jobs     ├─Resume Forge (STAR)           └─Apps     ├─Passport ├─Analytics
    └─Health   ├─Skills   ├─Interview Studio                Pipeline ├─Evidence └─Settings
               └─Learning └─Cover Letters                            └─Gov Data
```

### Cluster 1: COMMAND
- **`/overview` (Overview)**: Executive command center with Career Readiness Score, Opportunity Velocity, Active Agent Fleet, and Daily Priority Actions.
- **`/career-health` (Career Health)**: Skill Debt Index, Salary Trajectory Projections, and What-If Role Pivot Simulator.

### Cluster 2: DISCOVER
- **`/jobs` (Job Intelligence)**: Algorithmic job discovery feed with Proficiently Transparent Fit Ratings (`SKIP`, `LOW`, `MED`, `HIGH`), network referral matches, and Two-Phase ATS Application Prep.
- **`/skills` (Skill Intelligence)**: Real-time industry skill gap radar, wage delta impact per skill, and emerging framework demand.
- **`/learning` (Learning Paths)**: Government-accredited (SWAYAM, NPTEL, PMKVY) and open-source learning paths tied directly to closing identified skill gaps.

### Cluster 3: BUILD
- **`/resume` (Resume Forge)**: 3-column intelligent workspace: JD Requirement Vector -> Live Canvas -> Anti-Slop Flesch >90 & ATS Scoring. Includes Grounded Cover Letter Generator.
- **`/interview` (Interview Studio)**: Role-specific AI mock interviews with behavioral STAR evaluation and real-time verbal feedback.

### Cluster 4: TRACK
- **`/applications` (Application Pipeline)**: 5-stage Kanban board (Saved, Applied, Interviewing, Offer, Archive) synchronizing live status and Two-Phase ATS submission proofs.

### Cluster 5: VERIFY
- **`/passport` (Career Passport)**: Cryptographically verifiable career dossier, skill certificates, and public shareable profile URL.
- **`/evidence` (Code & Work Proof)**: GitHub commit analysis, repository impact scores, and verified code audit trails.

### Cluster 6: SYSTEM
- **`/analytics` (Government & Infrastructure Analytics)**: PulseAI-style infrastructure analytics, PMKVY / DDU-GKY / NAPS district enrolment cohorts, and training provider scorecards.
- **`/settings` (Settings & Privacy)**: Career preferences (dealbreakers, salary floor, target titles), work history database, BYOK AI keys, and DPDP Act 2023 compliance controls.

## 3. Dual-Navigation Interface Specification

### 3.1 Topbar (PulseAI Master Header)
- **Brand Identity**: Left-anchored vivid orange NEXIS mark with live 3D Agent status indicator.
- **Primary Pill Tabs**: Centered rounded capsule allowing instant 1-click switching:
  `[ Overview ] [ Jobs ] [ Resume ] [ Skills ] [ Analytics ] [ 3D Office ]`
- **Global Search**: Soft-tinted input (`Cmd+K`) searching across jobs, skills, contacts, and application records.
- **Agent Drawer Toggle**: Quick trigger to inspect live thoughts, logs, and active tasks across the 8 AI agents.

### 3.2 Collapsible Warm Left Sidebar
- **Section Headers**: Uppercase, tracking-wide micro-labels (`COMMAND`, `DISCOVER`, `BUILD`, `TRACK`, `VERIFY`, `SYSTEM`).
- **Interactive Items**:
  - Consistent 20px Lucide icons.
  - Active state: Warm ivory pill highlight (`#F2ECE2`), dark graphite text (`#181512`), and subtle orange edge indicator.
  - Count badges: Live job match counts, pending application updates, and skill debt counts.
- **Bottom Profile Card**: Active user avatar, current career readiness gauge, and settings/sign-out quick actions.
